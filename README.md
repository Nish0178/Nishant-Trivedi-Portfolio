# Nishant Trivedi — Portfolio

Premium personal portfolio foundation built with Next.js, TypeScript, Tailwind CSS, Motion, and React Three Fiber.

## Current phase

Phase 1 is the visual foundation: cinematic editorial layout, finalized walking-video hero, responsive navigation, scroll progress, motion, social rail, and section architecture.

Real projects, experience, achievements, links, contact details, and 3D interactions are intentionally left for the next verified-content passes.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3001
.
